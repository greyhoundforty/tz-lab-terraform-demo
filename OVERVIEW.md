# Lab Overview

In this lab, participants will delve into the command line interface for IBM Cloud and the Power Virtual Server plugin. Attendees will gain hands-on experience navigating and utilizing these tools to manage cloud resources effectively. By the end of the session, participants will be exposed to deploying Power Virtual Server using IBM Cloud using Ansible and Terraform. This lab is designed to equip IT professionals with the practical skills needed to automate and streamline cloud deployments, enhancing their ability to manage and optimize IBM Power environments.

## Tech Stack

- IBM Cloud VPC
- IBM Cloud VPC Virtual Instances 
- Terraform 
- Ansible 

## Session

- 90 minutes
